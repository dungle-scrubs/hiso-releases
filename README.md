# Hiso releases

Notarized downloads of Hiso, local dictation for macOS. Hiso's source is
not in this repository.

Download the latest ZIP from
[Releases](https://github.com/dungle-scrubs/hiso-releases/releases/latest).
Each ZIP has a `.sha256` file beside it. To check a download:

```bash
shasum -a 256 -c hisohiso-v*-darwin-universal.zip.sha256
```

Hiso runs on Apple Silicon and Intel Macs with macOS 14 or later.
